# Разбиение спецификации #19

Статус: черновик для согласования, задачи не опубликованы. Родительская спецификация: https://github.com/kindyakov/voxel-pilot/issues/19.

Каждая задача завершается наблюдаемым сценарием через общий интерфейс и нужные исполнители. До финального переключения новый путь проверяется изолированно, без одновременного управления ботом старым и новым пилотом. Узкое отделение запуска действия от старого модельного цикла выполняется в задаче T03 и проверяется сценарием добычи; отдельная широкая задача «рефакторинг AI» не нужна.

Зависимости показывают непосредственные блокировки. Существующие отдельные задачи по бою и выживанию не добавлены как блокеры: сохраняются действующие контракты харнеса, а их самостоятельное расширение не входит в эту спецификацию.

После согласования задачи публикуются в порядке зависимостей с меткой ready-for-agent. T-номера заменяются реальными ссылками. Родительская Issue не редактируется и не закрывается; связь указывается в дочерних задачах. Native blocking edges добавляются после проверки доступного контракта GitHub.
