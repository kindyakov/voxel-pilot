## What to build

Получить воспроизводимый путь «сообщение → выбранная модель RouterAI → безопасный тестовый инструмент → потоковый ответ» на опубликованном OpenAI Agents SDK. Результат используется последующими задачами как рабочая интеграция, а не выбрасываемая демонстрация.

Покрытие пользовательских историй спецификации: 33–35. Все решения о поведении принимает LLM; код обеспечивает контракты и исполнение. Это черновик для согласования разбиения; T-номера обозначают будущие задачи, а не опубликованные Issues.

## Acceptance criteria

- [ ] Закреплены совместимые опубликованные версии; модель и endpoint настраиваются без привязки к одному названию модели.
- [ ] Работают текстовый ответ, вызов инструмента, возврат его результата и продолжение SDK-loop. Нет собственной замены модельного цикла.
- [ ] Проверены streaming, отмена запроса и история следующего обращения после прерывания на выбранном протоколе RouterAI.
- [ ] Транспортный отказ, неверный JSON/аргументы и отмена различаются; ошибки разбора не превращаются в допустимый пустой вызов.
- [ ] Политика сетевых повторов имеет одного владельца: попытки SDK и обёртки не перемножаются.
- [ ] Есть воспроизводимая изолированная проверка с управляемой моделью и отдельный запуск реального провайдера без Minecraft. Недоступные учётные данные или возможности явно отмечены, а не заменены утверждением об успешной совместимости.
- [ ] Зафиксированы исходные задержки модельных обращений; отсутствует обещание двухсекундного старта на основании этого теста.
- [ ] Рабочий бот и его существующий пилот не изменяют поведение из-за подключения новой интеграции.
- [ ] Для изменённого кода выполнены проверка типов, сборка и релевантные изолированные тесты; обычная проверка не запускает живого бота.
