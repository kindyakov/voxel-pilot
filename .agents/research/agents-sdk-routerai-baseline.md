# Baseline model latency

Проверено: 2026-09-19. Это baseline сохранённого trace старого цикла для сценария «вскопай 5 песка»; он нужен для сравнения с новым изолированным пилотом и не является результатом live-проверки RouterAI.

| Ход                            | Время до решения | Обращения к модели |
| ------------------------------ | ---------------: | -----------------: |
| Первое решение и начало добычи |         9 251 мс |   5 137 + 4 093 мс |
| Повторное решение              |        14 943 мс |   6 860 + 8 068 мс |
| Финальный ответ                |        16 248 мс |  5 178 + 11 068 мс |

За trace обращения к модельному клиенту заняли 40 404 мс из 40 442 мс принятия решений. Первый вызов действия не укладывался в двухсекундный порог. Время включает сетевой клиент, обработку провайдера и возможные повторы; чистая генерация модели отдельно не измерялась.

Для нового пилота повторяемый live-прогон выполняется без Minecraft:

```text
npm run verify:agents-sdk:routerai
```

Команда читает `ROUTERAI_API_KEY`/`ROUTERAI_BASE_URL`/`ROUTERAI_MODEL` или соответствующие `AI_*`, проверяет streaming, отмену и продолжение истории, а в JSON-отчёте печатает время до первого события модели, завершения потока и продолжения после отмены. Без credentials команда завершается явным сообщением и не обращается к сети.
