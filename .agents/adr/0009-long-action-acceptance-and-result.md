# Подтверждение запуска и отдельный результат длительного действия

Статус: принято для проектирования; реализация ещё не изменена
Согласовано: 2026-09-19

Длительный execution-инструмент возвращает подтверждённый харнесом приём действия и его идентификатор либо отказ. Харнес выполняет действие и отдельно публикует прогресс и конечный результат. Принятие действия не означает успешного выполнения. Быстрые инструменты осмотра и чтения возвращают результат непосредственно в SDK-loop.

Конечный результат поступает пилоту как новый явно обозначенный факт исполнения в том же разговоре. Это не второй output завершённого tool call и не реплика игрока. LLM решает, как ответить и что делать дальше. Обработка инструментов и обращений к модели остаётся в OpenAI Agents SDK; приложение связывает этот цикл с харнесом.

Альтернатива — ожидать всю добычу внутри инструмента — удерживает запуск SDK и осложняет разговор во время действия. Выбранный контракт позволяет принимать сообщения независимо от длительности исполнения. Его цена — явная связь запроса, приёма, прогресса и исхода по идентификатору действия, доставка результатов и сохранение уже совершённых эффектов при прерывании ответа модели. Отмена ответа сама по себе не отменяет принятое харнесом действие.
