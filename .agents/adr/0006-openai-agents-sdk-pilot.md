# OpenAI Agents SDK как основа пилота

Статус: принято; изолированный T01-пилот реализован, переключение бота не выполнено
Согласовано: 2026-09-19

Для нового пилота выбираем OpenAI Agents SDK для TypeScript. Приоритет — готовая расширяемая агентская инфраструктура: цикл вызовов модели и инструментов, контракт sessions для истории разговора и возможность последующего делегирования. Выбор определяется направлением развития пилота, а не достаточностью библиотеки для текущего цикла. Введение нескольких агентов этим решением не предписывается.

## Границы

Сохраняем RouterAI с OpenAI-совместимым API и сменяемыми моделями. SDK отвечает за модельный цикл; диалог и исполнение разделяем по [ADR-0005](0005-pilot-dialogue-and-execution.md). Харнес остаётся единственным владельцем игровых действий, движения, выживания и отмены.

## Альтернативы и компромисс

Vercel AI SDK Core / ToolLoopAgent также предоставляет готовый цикл и провайдерные адаптеры. Выбрали OpenAI Agents SDK, чтобы опираться на его готовые агентские контракты при развитии диалога и оркестрации. Наличие XState не является основанием отклонять какой-либо из этих SDK: оба могут работать поверх харнеса.

Принимаем зависимость от модели исполнения SDK. Его sessions не заменяют проектирование постоянного хранилища и правил входящих сообщений во время работы. Возможности OpenAI Responses нельзя считать доступными через RouterAI без проверки. Версии пакетов, streaming tool calls, отмена и настройки reasoning проверяются при интеграции; SDK не гарантирует двухсекундный старт действия. Выбор библиотеки не означает, что совместимость и скорость уже проверены.

Изолированный адаптер T01 находится в `src/ai/agentSdkPilot.ts` и использует опубликованный `@openai/agents` 0.18.0 с OpenAI-совместимым Chat Completions endpoint. Он покрывает локальными тестами текстовый и инструментальный цикл, streaming, отмену, историю и классификацию ошибок; старый пилот и харнес пока не подключены. Совместимость с реальным RouterAI подтверждена отдельным live-прогоном, а достижимость целевой задержки требует серии измерений.

Live-проверка выполняется без Minecraft командой `npm run verify:agents-sdk:routerai` при заданных `AI_API_KEY`/`AI_BASE_URL`/`AI_MODEL` (или `ROUTERAI_*`). Скрипт использует безопасный тестовый tool, проверяет streaming, отмену и продолжение истории, а также печатает измерения до первого события модели, завершения потока и продолжения после отмены. Секреты в репозиторий не записываются.

Исторический baseline старого цикла и процедура сравнения записаны в [agents-sdk-routerai-baseline.md](../research/agents-sdk-routerai-baseline.md). Его значения не подменяют live-измерение нового адаптера.
