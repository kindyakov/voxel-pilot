# VoxelPilot

Языковые версии: [English](README.md) | [Русский](README.ru.md)

VoxelPilot - AI-бот для Minecraft на базе Mineflayer и XState. Бот подключается к серверу, строит детерминированный снимок состояния мира, запрашивает у модели одно следующее действие и выполняет его через иерархический автомат состояний.

## Что делает

- Подключается к Minecraft-серверу и реагирует на чат-команды игроков.
- Использует AI-loop для выбора между памятью, инспекцией мира, завершением цели и одним исполнительным действием (`IDLE -> THINKING -> EXECUTING -> DECIDE_NEXT`).
- Выполняет действия через примитивы: `navigate_to`, `break_block`, `mine_resource`, `place_block`, `follow_entity`, `open_window`, `transfer_item`, `close_window`.
- Ведёт персистентные задачи добычи (`tasks_list`, `tasks_create`, `tasks_start`, `tasks_cancel`): переживают рестарт как приостановленные, выполняются через HSM.
- Хранит долгосрочную память в SQLite в каталоге `data/`.

## Быстрый старт

1. Используйте Node.js 24+ и pnpm версии из `package.json` (`packageManager`); установите зависимости командой `pnpm install --frozen-lockfile`.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `MINECRAFT_*` и `AI_*`.
4. Запустите `pnpm run dev`.

## Терминальный дашборд

После настройки того же `.env` и `pnpm run build` запусти `pnpm run tui` в интерактивном терминале. Дашборд запускает одного бота, показывает подключение и журнал INFO+, сохраняет окончательный отказ до выхода. DEBUG собирается с запуска; console logging отключён, а файлы сохраняют свой настроенный уровень. CLI и TUI последовательно используют одни корневые пути данных и логов.

`d` показывает сохранённые DEBUG-записи. Стрелки вверх/вниз и PgUp/PgDn листают записи; прокрутка вверх фиксирует просмотр, счётчик показывает новые подходящие события. `End` или прокрутка вниз к последней записи возвращает LIVE. Фильтр и resize сохраняют якорь паузы; при вытеснении появляется отметка потери и первая сохранённая подходящая запись. Вытеснение и исходное усечение журнала остаются видимыми, сокращение текста на экране отмечено многоточием.

`q` или Ctrl+C останавливает runtime и ожидает сохранение. Сигналы и ошибки приложения присоединяются к одному ограниченному завершению; дедлайн или отказ сохранения дают ненулевой исход. Нужны интерактивные ввод/вывод и raw input. Неподдерживаемый терминал отклоняется до загрузки settings и создания ресурсов; headless CLI запускается через `pnpm start`. `pnpm run dev:tui` включает development watcher.

От 120 колонок журнал и статус занимают примерно 65/35 полезной ширины. При достаточной высоте vitals, позиция, HSM и цель разделены на блоки; низкое окно использует компактный статус. Узкое окно размещает компактный статус над журналом; при нехватке места появляется просьба увеличить окно, ввод и бот продолжают работать. PgUp/PgDn используют число видимых записей. Resize сохраняет фильтр, якорь паузы и время основного состояния. Длинный текст сокращается по терминальным ячейкам; `[усечено]` (или `[!]`/`!`) обозначает исходное усечение отдельно от сокращения на экране.

Оформление зависит от TTY и терминальных подсказок. `NO_COLOR` или `FORCE_COLOR=0` отключает цвета; `TERM=dumb`, `TERM=linux` или явно не-UTF8 locale упрощает декоративные символы до ASCII. Уровни, unknown/stale и пауза цели остаются текстом; сокращение обозначается `~`. Headless CLI остаётся стандартным запуском Docker.

## Docker

Один бот на контейнер: `docker compose up -d --build` (использует `.env`, тома `./data` и `./logs`, порты `3000`/`3001`). Для нескольких ботов продублируйте сервис со своим именем, `.env` и томами.

## Безопасность

- Не подключайте бота к серверам, которыми вы не управляете и на которые у вас нет разрешения.
- Бот пишет логи и persistent memory на диск.
- Перед публикацией проверяйте `data/` и `logs/`.
